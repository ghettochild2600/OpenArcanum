# First Enhanced UI Style Test Set

## Status

These assets are a proposed calibration set only. **No Enhanced artwork was generated by this audit.** Each future
test begins from the deterministic local retail export and follows `ui-remaster-pipeline.md`. Acceptance of this set
establishes a visual language; it does not authorize bulk generation.

All decoded paths are under `D:/OpenArcanum/UIReference/Original/`. Target dimensions are exactly 4x native. The
canonical Enhanced destination mirrors the source ID under `HDAssets/ui/by-source-id/`.

## Acceptance sequence

Process the set in the listed order only after UI-A defines the validator/index. After each asset or family:

1. validate exact dimensions, source identity, alpha, pivot and family registration;
2. inspect at raw 4x and source logical 1x;
3. exercise Original, Enhanced and missing-replacement fallback in the same UI fixture;
4. capture the three target resolutions;
5. reject any invented control/text, geometry drift or changed semantic meaning;
6. record the accepted visual decisions before moving to the next category.

The first production proof should use one small control and one compound frame, not replace an entire screen. The
Main Menu can then be the first bounded screen phase after the common resolver is accepted.
