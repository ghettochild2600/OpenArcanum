## Shared controls and reuse rules

Buttons, pressed/hover/disabled states, arrows, checkbox/radio controls, scrollbars, cursors, portrait/item frames,
confirmation windows, text colors/fonts, and invalid feedback belong to a common UI presentation package. The same
source identity may be used by multiple screens; screen directories must not duplicate its replacement pixels.

Original and Enhanced modes always share the same logical rectangle, pivot, hit rectangle, modal ordering, focus,
keyboard route, and controller command. A mode switch may rebuild presentation but cannot mutate screen state or
gameplay. Where no authoritative controller exists (notably Sleep/Fate and parts of Local Map), the screen remains
unavailable or read-only rather than silently adding gameplay.

## Character Creation usability requirement

At 1920 x 1080, 2560 x 1440, and 3840 x 2160, the complete primary 800 x 400 editor fits without horizontal
scrolling. Initial identity selection and fixed subpanels remain visible at the same logical geometry. Only source-long
lists may use a vertical scroller, with focus and keyboard behavior matching the original intent.
